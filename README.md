# 動画チェックツール

Premiere Pro XML、mp4、txtファイルを読み込んで、動画の品質をチェックするブラウザベースのツールです。

## 機能

- **ギャップ検知**: Premiere Pro XMLからタイムライン情報を読み取り、クリップ間のギャップを検出
- **フラッシュフレーム検知**: 動画内の一瞬の黒画面（フラッシュフレーム）を検出
- **音量チェック**: 動画の音量レベルを分析し、お手本動画と比較
- **誤字脱字チェック**: タイムコード付きテキストファイルの誤字脱字をGemini APIでチェック
- **CSV出力**: 検出したエラーをCSV形式でエクスポート

## セットアップ

### 必要な環境

- Node.js 18以上
- npm または yarn

### インストール

```bash
npm install
```

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで `http://localhost:5173` を開きます。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist` ディレクトリに出力されます。

## 使用方法

1. **バックエンドAPIの設定**（誤字脱字チェックを使用する場合）
   - このツールはバックエンドAPI経由でGemini APIを呼び出します
   - APIキーはサーバー側で管理されるため、ユーザーが入力する必要はありません
   - **Vercelにデプロイする場合**:
     - Vercelのダッシュボードで環境変数 `GEMINI_API_KEY` を設定してください
     - GitHubと連携していれば、プッシュするだけで自動デプロイされます
   - **ローカル開発環境でテストする場合**:
     - Vercel CLIをインストール: `npm i -g vercel`
     - `vercel dev` を実行してローカルでAPIを起動
     - または、`.env.local` に `GEMINI_API_KEY` を設定して `vercel dev` を実行

2. **ファイルのアップロード**
   - **Premiere Pro XML**: タイムライン情報を含むXMLファイル
   - **チェック対象動画 (MP4)**: チェックする動画ファイル
   - **テロップテキスト (TXT)**: タイムコード付きのテキストファイル（形式: `HH:MM:SS:FF テキスト内容`）
   - **お手本動画 (MP4)**: 音量比較用の参考動画（オプション）

3. **チェック実行**
   - 「チェック開始」ボタンをクリック
   - 処理が完了すると、結果がテーブルに表示されます

4. **CSV出力**
   - 結果テーブルの「CSV出力」ボタンをクリック
   - エラー情報がCSV形式でダウンロードされます

## テキストファイル形式

テキストファイルは以下の形式で記述してください：

```
00:00:01:00 こんにちは
00:00:05:15 これはテストです
00:00:10:30 誤字脱字をチェックします
```

各行は `HH:MM:SS:FF テキスト内容` の形式で記述します。

## 技術スタック

- **フレームワーク**: React + Vite
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **バックエンド**: Vercel Serverless Functions
- **XML解析**: xml2js
- **CSV出力**: papaparse
- **AI API**: Google Gemini API（バックエンド経由）
- **動画解析**: ブラウザのVideo API（将来的にffmpeg.wasmを統合予定）

## 注意事項

- 大容量の動画ファイルを処理する場合、時間がかかる可能性があります
- 音声解析機能は現在、動画ファイルを直接AudioBufferに変換しようとしますが、多くの場合失敗します。将来的にffmpeg.wasmを使用した音声抽出を実装予定です

## セキュリティについて

- **APIキーの扱い**: Gemini APIキーはバックエンド（Vercel Serverless Functions）で管理されます
- APIキーはクライアント側に露出せず、サーバー側の環境変数でのみ管理されます
- コード内にAPIキーはハードコードされていません
- **重要**: Vercelの環境変数 `GEMINI_API_KEY` を設定してください（Vercelダッシュボードから設定可能）
- 公開リポジトリでも安全に使用できます（APIキーは環境変数で管理されるため）

## デプロイ方法

### Vercelへのデプロイ

1. [Vercel](https://vercel.com)にアカウントを作成
2. GitHubリポジトリをVercelに接続
3. 環境変数 `GEMINI_API_KEY` を設定（Vercelダッシュボード > Settings > Environment Variables）
4. デプロイが自動的に開始されます

### ローカル開発

```bash
# Vercel CLIをインストール（初回のみ）
npm i -g vercel

# ローカルでAPIを起動
vercel dev
```

別のターミナルで：
```bash
# フロントエンド開発サーバーを起動
npm run dev
```
